# 🛡️ Cybersecurity & Security Analytics Portfolio

أهلاً بك! يضم هذا المستودع مجموعة من الأدوات والتطبيقات الخاصة بتحليل السجلات الأمنية (Log Analysis) وجمع معلومات التهديدات (OSINT).

---

## 📂 المشاريع الموجودة في المستودع

### 1. 📊 OSINT Security Dashboard
تطبيق متكامل مبني بلغة Python/Flask وJavaScript لتشخيص وتتبع عناوين IP المشبوهة، وتحليل سلوك الهجمات ورسم خريطة حية لمصادر التهديدات.
* **الملفات:** `app.py`, `log_parser.py`, `osint_module.py`, `behavior_analyzer.py`, `dashboard.html`

---

### 2. ⚡ Standalone Log Analyzer
سكربت سريع ومستقل لمعالجة ملفات السجلات الضخمة وحساب التهديدات مع لوحة عرض تفاعلية تعمل عبر المتصفح.
* **الملفات:** `analyze_logs.py`, `log_analyzer_ui.html`

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Languages:** Python 3, JavaScript (ES6+), HTML5, CSS3
* **Frameworks:** Flask, REST APIs
* **Security & Intel:** OSINT IP Geolocation, Behavioral Pattern Analysis, Regex Log Parsing
